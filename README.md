# ClassManager

An offline-first classroom manager for lecturers and students, built as two apps that share one data format:

| | Location | Platforms | Built by |
|---|---|---|---|
| **Web app** (React + TypeScript + Vite, installable PWA) | `web/` | Any modern browser, phone or PC | `.github/workflows/web.yml` → GitHub Pages |
| **Flutter app** | `app/` | Android (APK) and Windows | `.github/workflows/flutter.yml` → downloadable artifacts |

Backups and student share files made by one app open in the other.

## What lecturers can do

- **Courses**: code, section, semester, room, credit hours, weekly schedule, section cap, custom grade scale.
- **Roster**: add one student, or paste a roster (`student no, name, email, phone`; commas or tabs). Duplicates are skipped.
- **Attendance**: sessions generated from the schedule, Present / Late / Absent / Excused per student, "everyone present", per-session topic, summary view. Late counts half; Excused is not counted. Attendance can optionally carry marks (set its weight in course settings).
- **Gradebook**: weighted assessments, score entry grid, current *standing* (over graded work), letter grade, class rank (ties share a rank). Empty cell = not graded yet (skipped); 0 = a real zero.
- **Analysis**: mean, median, high/low, standard deviation, pass rate and a score histogram per assessment.
- **Insights** (web): score and attendance heat maps, a "what do I need on the final?" calculator per student, and a grade-curve preview.
- **Groups** (web): balanced project groups dealt out by standing, printable and exportable.
- **Calendar** (web): week-by-week view of sessions, topics and assessment due dates.
- **Sample class**: one tap on the dashboard loads a 35-student demo course.
- **At-risk register**: flags low attendance, low standing and missing scores, with email/call links.
- **Announcements**, pinned or not.
- **Reports** (web): gradebook CSV, attendance CSV, registrar grade sheet, sign-in sheet, per-student progress report (print or save as PDF).
- **Backup / restore** of everything as one JSON file.

## What students can do

Students open the **Student** tab, load the *share file* their lecturer sent, and sign in with their student number and personal PIN to see their attendance record, scores, standing, rank and announcements.

### How student privacy works without a server

Each student's record inside the share file is encrypted with **their own PIN** (PBKDF2-HMAC-SHA256, 100,000 iterations → AES-256-GCM, random salt and IV per student). The file can be posted in a class WhatsApp group: opening someone else's record needs their PIN. Student numbers are visible in the file; names, scores and attendance are not. Use "Reset all PINs" in the roster if a PIN leaks. The share file is a snapshot, so send a fresh one after you update attendance or scores.

Format spec: `web/src/share.ts` (web) and `app/lib/services/share_service.dart` (Flutter) implement the same layout.

## Run it

**Web**
```bash
cd web
npm install
npm run dev        # http://localhost:5173
npm test           # grading logic, share-file crypto, every screen renders
npm run build
```
Enable GitHub Pages once: *Settings → Pages → Source: GitHub Actions*. Each push to `main` that touches `web/` then deploys the site.

**Flutter**
```bash
cd app
flutter create --platforms=android,windows --project-name classmanager --org com.classmanager .
flutter pub get
flutter test
flutter run -d windows     # or an Android device
```
The `android/` and `windows/` folders are generated by `flutter create` (they are git-ignored), and the CI workflow does the same before building. After a push, download `classmanager-android-apk` and `classmanager-windows` from the workflow run's *Artifacts*.

## Data and limits (v1)

- All data lives on the device (browser storage / app storage). There are no accounts or cloud sync yet, so back up regularly.
- Students are read-only viewers: they cannot submit attendance or work. A future version can add a Firebase or Supabase backend so students sign in live.
- Printable and CSV reports exist only in the web app so far; the Flutter app does not have them yet.
